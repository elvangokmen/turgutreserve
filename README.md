# Turgut Reserve — Final GitHub/Vercel Package

This clean Next.js package contains the complete trilingual land-sales website:

- Turkish, English and Arabic language switching
- RTL layout support for Arabic
- original uncropped drone video in its natural widescreen ratio
- separate Commercial Luxury Glamping and Twin Mobile Family Estate sections
- approved project renders and masterplans
- clear land-only asking-price and separate-implementation disclosures
- responsive desktop and mobile layouts

## Upload

1. Extract the ZIP file.
2. Upload every extracted file and folder to the root of the GitHub repository.
3. Keep the `app`, `public`, `package.json` and `package-lock.json` paths intact.
4. Vercel will detect Next.js and redeploy automatically.

Do not upload the ZIP file itself into the repository.
