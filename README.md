# Turgut Reserve — Eco‑Tourism Glamping & Private Luxury Tiny House Estate

This is the clean GitHub/Vercel deployment package for one undivided,
three-co-owner property with two distinctly presented project visions:
commercial eco-tourism glamping and a high-privacy private tiny house estate.

It contains only:

- `public/hero.mp4` — drone hero video
- `public/concept/` — low-impact Glamping & Eco‑Retreat visuals
- `public/tiny/` — Maxi/Loft XL mobile estate visuals
- Turkish, English and Arabic website content
- a single-title, three-co-owner internal use plan
- a two-project selector and separate project galleries
- a compliance-led strategy with no conventional concrete-building claim
- Property facts, asking price and private enquiry section

It does not contain old parcel photographs, conventional reinforced-concrete
residence renders, in-ground concrete pool renders, `node_modules` or `.next` output.

## Deploy

1. Create a new, empty GitHub repository or delete all existing files in the current repository.
2. Upload every file and folder from this package to the repository root.
3. Import the repository into Vercel, or allow the existing Vercel project to redeploy.

Vercel will detect Next.js automatically. No Tailwind CSS, Lucide or other UI dependency is required.
